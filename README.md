# Classic Tetris

A browser-based classic Tetris game under development. The current checkpoint is project preparation; a playable application has not yet been delivered.

The intended game includes movement, rotation, soft drop, line clearing, scoring, levels, pause and restart. Shared TypeScript game logic and UI will keep browser-specific integration separate for reuse in future delivery platforms.

See the [project brief](docs/dev/PROJECT.md) for scope and the [development handoff](docs/dev/HANDOFF.md) for the current workflow checkpoint. Setup and gameplay instructions will accompany the delivered application.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
