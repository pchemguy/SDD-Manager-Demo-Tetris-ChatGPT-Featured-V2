# Controls and classic rules

Click Start game. The playfield receives keyboard focus; click it to regain focus when needed.

| Key | Action |
| --- | --- |
| Left / Right | Move one column |
| Down | Soft drop |
| Up / X / Space | Rotate clockwise |
| Z | Rotate counterclockwise |
| C / Shift | Hold piece |
| P / Escape | Pause or resume |
| Enter | Start a ready game |
| R | Restart |

Native rotation, Start, Pause/Resume and Restart buttons are keyboard operable. Focus leaving the game, window blur or hiding the page pauses play; return does not resume automatically. Resume explicitly. Restart and reload discard the session; there is no saved game.

A grounded piece locks after one full current gravity interval from landing. Blocked soft drops and grounded moves/rotations do not shorten or reset that countdown. Leaving support cancels it; landing again grants a full interval. Pause freezes it. Rotation uses both-direction SRS kicks within the visible board. In this intermediate milestone, Space remains a clockwise alias; hard drop and ghost are not delivered yet. Each bag contains all seven shapes once, with possible repeats across bag boundaries. The Next panel shows only the single next piece, including across refills. Hold exchanges the active type once per lock. An empty slot consumes Next; an occupied slot swaps without consuming it. Replacements use spawn orientation and fresh timers; holding awards no points. Numeric scores and speed are unchanged.

Clear one/two/three/four rows for 40/100/300/1200 points multiplied by the pre-clear level. Soft drop adds one point per row. Level increases every ten total lines; gravity accelerates to a 100 ms minimum. A blocked spawn ends the game. Use Restart for another try.
